# DocMivo V18.2 — إصلاح اختبارات تقسيم وترتيب الصفحات

هذا تحديث **إضافي** لـCloudflare V18.1؛ لا يغير ربط الدومين ولا يفعّل أي API مدفوعة.

## ما الذي يتغير؟

- Split PDF: رفض نطاقات فيها أجزاء فارغة مثل `1-2;;4-5` أو `1-2;` بدل التجاهل الصامت.
- Reorder PDF: رفض أرقام الصفحات المكررة، والناقصة، والخارجة عن نطاق الملف؛ لا يُسمح بترتيب يوحي بالنجاح مع مدخل غير صحيح.
- اختبارات Node إضافية تضمن صحة التحليل وتمنع نجاح بناء صامت بعد تغيير الكود.
- سكريبت QA اختياري لمقارنة PDF الناتج فعليًا بالملف الأصلي، بما يشمل عدد الصفحات والنص والتطابق البصري.

## خطوات الرفع

1. فك ضغط الحزمة.
2. GitHub → `Gerges7/docmivo` → `main` → Add file → Upload files.
3. ارفع محتويات `cloudflare` بالمجلدات، ووافق على تعديل `cloudflare/package.json`.
4. تأكد أن المسار النهائي `cloudflare/scripts/pdf-page-hardening.mjs` وليس `cloudflare/cloudflare/...`.
5. Commit changes. المفترض أن Cloudflare يعيد النشر تلقائيًا (`npm run test && npm run build`, ثم `npx wrangler deploy`).

## اختبار Split PDF يدويًا بعد النشر

1. افتح https://getdocmivo.com/tools/split-pdf
2. ارفع `merged.pdf` الذي نتج من اختبار Merge السابق (17 صفحة).
3. اكتب في `النطاقات`: `1;2-17` ثم شغّل العملية.
4. المتوقع تنزيل `split-pdf.zip` وفيه `part-1.pdf` (صفحة واحدة أصلية) و`part-2.pdf` (16 صفحة أصلية)، بالترتيب.
5. أرسل ZIP الناتج إلى ChatGPT للفحص باستخدام الملف الأصلي.
6. اختبر إدخال `1;;2-17`: **يجب** ظهور خطأ، وليس تنزيل ZIP ناجح.

## التحقق المحلي الاختياري

`python cloudflare/qa/verify_split_zip.py merged.pdf split-pdf.zip '1;2-17'`

## الحالة

الاختبارات البرمجية من الكود **ليست بديلًا** عن تنفيذ العملية في المتصفح والتحقق من ZIP الناتج. لا نعتبر Split PDF معتمدًا إنتاجيًا حتى تمر هذه الحالة الواقعية.
