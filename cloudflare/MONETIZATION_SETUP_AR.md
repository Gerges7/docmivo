# نظام الإعلانات متعدد الشبكات — DocMivo

## الحالة الحالية

- جميع إعلانات الإنتاج **متوقفة افتراضيًا** (enabled=false).
- لا يتم تحميل كود AdSense أو Adsterra أو أي شبكة أخرى قبل تفعيل شبكة معتمدة وموضع صالح وموافقة المستخدم.
- مواضع العرض المجهزة: الصفحة الرئيسية، مركز الأدلة، ومقالات الأدلة فقط.
- صفحات أدوات PDF، الصفحات القانونية، التواصل، والإدارة مستثناة.
- لا توجد Pop-ups أو Pop-unders أو Push Notifications أو Smartlinks أو تحويلات تلقائية.
- لا توجد أي Publisher IDs أو Ad Unit IDs مختلقة.
- ملف ads.txt الحالي لم يتغير؛ لا تضف أي سجل لشبكة إلا بعد استلام السطر الرسمي من حساب الناشر.

## Architecture

- src/monetization.mjs: الإعدادات الافتراضية، التحقق من الشبكات والمواضع، Public Config API، Admin API، وتقارير Adsterra.
- assets/js/consent-manager.js: موافقة مستقلة على Analytics والإعلانات؛ الرفض هو الحالة الافتراضية، ويحترم GPC وDNT.
- assets/js/monetization.js: تحميل Adapter الشبكة المختارة فقط عند وجود موضع صالح وموافقة صريحة.
- scripts/adsense-page-scope.mjs: إزالة محمّل AdSense القديم، إضافة Consent Mode defaults، وإضافة مواضع المحتوى المسموح بها.
- admin/monetization/index.html: لوحة إدارة محمية برمز سري.
- ADSTERRA_API_TOKEN وADS_ADMIN_TOKEN أسرار Worker فقط، ولا يعاد أي منهما للمتصفح.

يوجد Provider نشط واحد للموقع في الوقت الحالي؛ يمكن تهيئة أكثر من شبكة وتبديلها مركزيًا دون تغيير مكونات الصفحات. هذا مقصود لمنع تداخل أكواد الشبكات أو تكرار الإعلان في الموضع نفسه. Monetag لا يملك Adapter عرض نشطًا لأن التنسيقات التي لا تتعارض مع قيود التجربة لم يتم التحقق منها بعد.

## إعداد Cloudflare المطلوب مرة واحدة

من مجلد cloudflare/ في المشروع:

1. أنشئ KV Namespace باسم DOCMIVO_ADS_CONFIG في Cloudflare.
2. أضف Binding باسم ADS_CONFIG_KV يشير إلى هذا الـNamespace. احتفظ بالـNamespace ID لإضافته إلى wrangler.jsonc حتى يستمر الربط مع النشر الآلي.
3. أضف Worker Secret باسم ADS_ADMIN_TOKEN بقيمة عشوائية قوية لا تقل عن 32 بايت. لا تضعها في GitHub أو في أي ملف.
4. بعد اعتماد Adsterra فقط، أضف Worker Secret باسم ADSTERRA_API_TOKEN من Settings → API في حساب الناشر. لا ترسله في المحادثة ولا تضعه في الواجهة.
5. افتح https://getdocmivo.com/admin/monetization وأدخل ADS_ADMIN_TOKEN. لوحة الإدارة لا تحفظ الرمز في Local Storage.

إذا لم يكن ADS_CONFIG_KV مربوطًا، ستعمل الصفحات مع الإعلانات متوقفة، لكن حفظ الإعدادات من لوحة الإدارة سيعيد HTTP 503. هذا مقصود وليس فشلًا صامتًا.

## تهيئة Adsterra بعد موافقة الموقع

1. أنشئ حساب Publisher وأضف getdocmivo.com وانتظر موافقة الموقع.
2. اختر Banner ثابتًا فقط. لا تختَر Popunder أو Social Bar أو In-Page Push أو Smartlink أو Interstitial.
3. أنشئ وحدات منفصلة للمقاسات الملائمة:
   - Desktop: 728x90
   - Mobile: 320x50
4. الصق كود Banner الذي يصدره Adsterra نفسه في موضع الصفحة المناسبة. لا تكتب Zone ID يدويًا ولا تعدل الكود.
5. أدخل Domain ID وPlacement ID الرسميين في لوحة الإدارة. استخدم Placement ID مختلفًا لكل موضع تريد قياسه منفصلًا، ولا تعِد استخدام zone key بين صفحات مختلفة.
6. اترك Feature Flag متوقفًا أثناء الاختبار. بعد التحقق من الموافقة، الكود والمقاسات وConsent، فعّل Provider والمواضع ثم فعّل Feature Flag.

يتحقق Adapter من صيغة atOptions الخاصة بـiframe Banner، ومن ملف JavaScript خارجي على نطاقات Adsterra المعروفة وبمسار invoke.js، وبمقاس مسموح. إذا أصدر حسابك نطاقًا مختلفًا، لا توسّع قائمة النطاقات عشوائيًا؛ راجع الكود الرسمي مع المطور أولًا.

## التقارير الفعلية

GET /api/monetization/reports?start=YYYY-MM-DD&end=YYYY-MM-DD

يُستدعى من لوحة الإدارة فقط باستخدام Bearer ADS_ADMIN_TOKEN. الخادم يرسل ADSTERRA_API_TOKEN في ترويسة X-API-Key إلى Publisher API الرسمي. لا يتم تمرير الرمز إلى Frontend.

تُعرض Impressions وClicks وRevenue وRPM عندما يعيدها تقرير الشبكة. RPM = Revenue ÷ Impressions × 1000. لا تُعرض أرقام تقديرية على أنها أرباح فعلية، ولا يتم تسجيل النقرات داخل الموقع. يجب إضافة Placement ID مستقل لكل موضع حتى يمكن ربط تقرير الشبكة بصفحة محددة.

## الخصوصية والموافقة

- يبدأ Consent Mode في Google Analytics بحالة denied، ولا يُرسل page_view حتى يختار المستخدم قياس الزيارات.
- الإعلانات لا تُحمّل قبل موافقة المستخدم على الإعلانات.
- يتم احترام Global Privacy Control وDo Not Track.
- لوحة الموافقة الحالية First-party preference gate وليست Google-certified TCF CMP.
- يحدد Cloudflare بلد الزيارة؛ في EEA والمملكة المتحدة وسويسرا يمنع Adapter الخاص بـAdSense التحميل ما لم توجد واجهة TCF وتُرجع TC String صالحة. قبل تشغيل AdSense لهذه المناطق يجب ربط CMP معتمد من Google ومتوافق مع IAB TCF؛ لا تعتبر لوحة الموافقة الحالية بديلًا عن ذلك.
- مفاتيح تقارير الشبكات تحفظ في أسرار Cloudflare ولا تُرسل إلى المتصفح.
- راجع Privacy Policy وCookie Policy بعد أي تغيير في الشبكة النشطة. أضف سجل ads.txt الرسمي الخاص بالشبكة فقط إذا طلبته الشبكة وقدّمته لحساب الناشر.

## تقييم الشبكات والدفع في مصر

- **Adsterra — تجربة أولى لـDocMivo بحذر:** لا تشترط حدًا أدنى للزيارات بحسب معلومات الناشر، لكن Adsterra نفسها تشير إلى أن المواقع التعليمية قد لا تكون أفضل niche لبعض الحملات. لذلك نبدأ باختبار Banner فقط ونقيس Fill Rate وRPM الفعليين قبل التوسع. قائمة Hyperwallet للتحويل البنكي المحلي المنشورة من Adsterra لا تتضمن مصر؛ طرق السحب الأخرى الظاهرة في حساب الناشر هي المرجع النهائي، ولا نفترض توفر PayPal أو Paxum أو التحويل البنكي لحساب مصر.
- **Infolinks — ليس خيارًا أوليًا لـDocMivo:** يمكن تقييمه في أدلة GoAcadio فقط، مع InFrame على Desktop، وإيقاف InText وInFold وInTag حتى لا يقطع الإعلانات قراءة النص. صفحة دعم Infolinks تذكر أن PayPal غير متاح للناشرين في مصر، بينما حد Payoneer المنشور $50؛ يجب تأكيد توفر Payoneer لحسابك المصري قبل الاعتماد عليه.
- **Monetag — غير مفعّل:** لم نجد سببًا كافيًا لاستخدامه مع قيود منع Pop/Push/Vignette والتحويلات. طرق الدفع المنشورة تشمل Payoneer بحدود $20/$30، وPayPal/Skrill/WebMoney بحدود $5، وWire بحد $500؛ لكن إتاحة كل وسيلة تعتمد على بلد الحساب.
- **Media.net — أولوية منخفضة:** يتطلب قبول كل موقع ومحتوى أصليًا عالي الجودة وسياسة خصوصية وإعلانات متوافقة مع Better Ads Standards. لا ينشر اتفاق الناشر العام حدًا موحدًا للدفع؛ اطلب شروط الدفع كتابيًا قبل التسجيل. الجمهور المصري/العربي يجعلها ليست خيار البداية.
- **Google AdSense — احتياطي مستقبلي:** يبقى خيارًا بعد قبول الموقع وربط CMP معتمد عند الحاجة. لا يتم تحميل AdSense تلقائيًا حاليًا.

## إيقاف فوري

- من لوحة الإدارة ألغِ Enable all ads.
- عند الحاجة التشغيلية الطارئة، أوقف enabled من إعدادات KV.
- عند حذف KV أو تعطل قراءته يعود Worker إلى الإعدادات الافتراضية المغلقة، ولا يحمّل أي شبكة.
