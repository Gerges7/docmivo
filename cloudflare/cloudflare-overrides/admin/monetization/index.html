إدارة تحقيق الدخل — DocMivo

إعدادات الشبكات الإعلانية والتقارير الفعلية. جميع الإعلانات متوقفة افتراضيًا.

العودة للموقع ←

1. الاتصال الآمن

لم يتم الاتصالتقارير Adsterra غير متصلة

لا يتم حفظ المفتاح في المتصفح أو Local Storage.

أضف KV binding باسم ADS_CONFIG_KV وSecret باسم ADS_ADMIN_TOKEN في Cloudflare لتفعيل الحفظ.

2. التحكم العام والشبكة

استخدم InFrame فقط على صفحات المحتوى المكتبي، وأوقف InText وInFold وInTag من حساب Infolinks. لا يتم عرضه على الموبايل أو الأدوات.

Desktop banner فقط؛ لا يتم تحميله على الموبايل.

تم تعطيل Monetag في هذا النظام لأن التنسيقات الرسمية الشائعة تشمل OnClick وPush وVignette/In-Page Push. لن نحمّلها. يمكن مراجعة أي تنسيق Banner ثابت آخر قبل إضافته.

الموافقة على الشبكة مطلوبة منفصلة عن تشغيل النظام. لا يكفي إدخال كود الإعلان وحده لبدء العرض.

3. أماكن الإعلانات — صفحات المحتوى فقط

لا توجد وحدات إعلانية داخل أدوات معالجة PDF أو صفحات الخصوصية أو التواصل أو الإدارة. اختر جهاز العرض والصق الكود الذي تولّده الشبكة بعد الموافقة فقط.

4. حفظ الإعدادات

النظام متوقف افتراضيًا. لا تفعّل الإعلانات قبل موافقة الشبكة واختبار الوحدات.

5. تقارير الشبكة والإيرادات

الأرقام هنا تُجلب من Adsterra Publisher API فقط. لا يتم تقدير النقرات أو الأرباح محليًا. لا يتم تتبع نقرات المستخدمين داخل الموقع.
